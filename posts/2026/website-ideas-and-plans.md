Did you know I have a website? I bet you did, given that you're reading this post. Sometimes I forget.

I'm trying to spend a little more time writing stuff on here, and building things I've wanted to build for a while, because there's lots I want to write about, and lots of neat things I want to make!

To that end, you might be interested in knowing about these things:

* I am tracking things I want to put on the website [in GitHub Issues](https://github.com/an-empty-string/website/issues) now! Check it out and feel free to comment on something if you find it interesting, want to see more like it, or whatever else. I don't have analytics or comments or anything like that on this site, so I don't really know what is useful or interesting to my audience. Or if I even have an audience!
* I am working on a couple of cool, interconnected features that will make it easier to stay up to date with what's happening on this website + what I've been up to:
    * I'm working on adding a map of places I've been! It's not anywhere close to done, but once it is, you'll be able to see points on a map and click them for more info. I intend to use this to recommend food spots, underappreciated places in cities I've lived in, keep track of towers I've rung in, things like that.
    * I'm generalizing types of content on this website (bookmarks, places, and blog posts) into a single thing with the "items framework." The goal is to be able to push new things to ActivityPub (so you can follow the website (or just parts of it) on Mastodon or other fediverse software) and put more things in RSS. Also there will finally be tags!!!
* Beeminder [bugs me about touching website todo items](https://www.beeminder.com/tris/website#data) now, so I'm much more likely to actually set aside time to work on this stuff! In fact, I am writing this very post because it's a beemergency day today. I don't yet know if I'll keep that up long term, but so far it's been quite nice to have the forcing function. This will probably mean more frequent but shorter posts!

Anyway, lots more stuff coming soon! Check out the [RSS feed](/blog/rss.xml) if you aren't already subscribed.
